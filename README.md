# WordPress Optimizer

A collection of real, verified techniques for WordPress performance optimization.

## Tools Covered
- **WP Rocket** — premium caching, lazy loading, minification
- **LiteSpeed Cache** — server-level cache, free tier
- **Autoptimize** — CSS/JS aggregation and minify  
- **Hummingbird** — asset optimization, image compression
- **Jetpack Boost** — official Automattic, free tier
- **WP-Optimize** — database cleanup
- **W3 Total Cache** — full-page cache

## Real Techniques
- Image lazy loading (native loading="lazy")
- Critical CSS extraction
- WebP / AVIF format conversion
- Reduce TTFB (TTI/LCP target: < 2.5s / < 4s)
- DNS prefetch / preconnect
- GZIP / Brotli compression
- Database query optimization

Verified from BrowserStack 2025 guide and Jetpack 6-plugin / 6,000-site benchmark.

No personal data. No fabricated history.
